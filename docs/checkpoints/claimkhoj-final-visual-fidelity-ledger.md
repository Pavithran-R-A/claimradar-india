# ClaimKhoj visual fidelity ledger

Accepted reference: PraptiQ homepage concept supplied by the product owner.

| Area | Reference intent | Implemented correction | Intentional deviation |
| --- | --- | --- | --- |
| Hero composition | Editorial left hero + prominent interactive source instrument | Tightened heading scale, vertical rhythm, search width, and right-column balance | Uses ClaimKhoj copy and real product claims only |
| Search | Large white search with marigold action | Marigold Search Claims CTA, refined focus/elevation and target sizing | Retains All India selector and truthful search behavior |
| Source instrument | Large colorful radial instrument plus side inspector | Expanded instrument, differentiated source accents, six-second beam, persistent Source Spotlight | Shows only SEBI/RBI/IBBI/TRAI/PIB; no invented authorities |
| Editorial journey | Flowing dotted route with handwritten civic annotations | Added wavy SVG journey, document sketch, handwritten notes, DISCOVER/VERIFY/UNDERSTAND/ACT | Uses truthful action language instead of implying payout receipt |
| Source strip | Distinct authority cards | Added authority-specific accent/pale treatments and stronger hover elevation | Five actual monitored source families only |
| Lower content | Dense opportunity list + four-step explainer | Reduced row height, improved hierarchy, colored step medallions, civic benefit strip | Data remains registry/database-backed |
| Motion | Visible but restrained scan and entry motion | Six-second sweep, blips, route draw, hover/focus motion, existing reveal system | Reduced-motion users keep all state without repeating motion |
| Truth & accessibility | Consumer-friendly but trustworthy | Keyboard nodes, ARIA pressed states, source inspector, truthful non-live disclaimer | No fake scan progress, no filing or payout promise |

## Above-the-fold copy

Approved visible copy retained/adapted:

- ClaimKhoj
- Find what’s rightfully yours.
- Search Claims
- All India
- Official sources we check
- Source Spotlight
- Discover / Verify / Understand / Act

No unsupported government-affiliation, guaranteed-eligibility, live-feed, or claim-filing language was added.
